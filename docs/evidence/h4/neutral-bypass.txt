H4 item 4 — neutral-value bypass (measured 2026-10-26, same machine, headless Chromium)

Setup: 4K fixture, the six-effect stack (posterize, edges, sketch, emboss, blur,
sharpen), both caches disabled so only pipeline cost is measured. Every render
is a real render of the full preview (1600x1200). Median of 6 measured renders
after one warm-up.

A. What a neutral value costs today, before the change
   all five neutral (edges 0, sketch 0, emboss 0, sharpen 0, blur 0)
   median 543.8 ms   runs [476.3, 502.0, 520.6, 543.8, 549.6, 562.4]

   Per neutral stage (stack with that one stage removed, same neutral values):
     edges   64.8 ms
     sketch  67.9 ms
     emboss 230.0 ms
     sharpen 218.6 ms
     blur    54.3 ms

   The two convolution stages dominate: fxConvolve ran its full 9-tap loop over
   every pixel even when amount = 0, where the result is a copy (the only other
   work is its existing opaque-alpha policy).

B. After the change
   all five neutral, 4K pipeline: median 128.5 ms
   runs [124.0, 124.4, 126.2, 128.5, 134.5, 149.1]
   delta 415.3 ms, 76.4% lower.

   Residual: with those five effects disabled entirely the same stack takes
   109.2 ms, so the remaining cost of the neutral stages (canvas copies that
   the alpha policy requires) is ~19 ms.
