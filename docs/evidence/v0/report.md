## 4. Owner symptom → measured cause

| Symptom | Measured evidence | Cause |
|---|---|---|
| 1. Export gives one still | default format `png`; download is `glyphcraft.png`, 1280×720, 502398 bytes | `exportImage` treats every non-webm format as a still (`app.js:1723-1749`); there is no MP4 option. |
| 2. Frames alternate clean / blocky / striped | paused backing 1280×720; playing backing 755×425 (Chromium) and 640×360 (Firefox); paused 20/20 parity pass | `render` deliberately swaps `previewSize(full)` for `previewSize(full, state.playback.scale)` while playing (`app.js:759-761`), and the governor shrinks the scale further (`app.js:618-674`). The CSS transform keeps the on-screen size, so the canvas is upscaled from fewer pixels. |
| 3. No seek control | `#video-seek`, `#video-back`, `#video-forward` absent | only the play/pause button exists (`index.html:104`). |
| 4. Output controls greyed for video | all five controls report `disabled: true` | `syncOutputControls` disables them for video (`app.js:1167-1176`). |
| 5. No MP4 | format option list has no `mp4`; `select_option('mp4')` times out | `index.html:428-436`, `exportVideo` hardcodes WebM/MediaRecorder (`app.js:1794`). |
| 6. Slider/compare freeze on large images | Chromium compare drag on 4K + 6 effects: 0 long tasks, p95 16.7 ms | Not reproduced in Chromium in the compare-split path (the Worker is eligible for images). The effect-slider path and Firefox are still to be measured in V5; see hypotheses below. |

The three status times are explained by the same mechanism: the status shows
`state.lastRender`. At 15 ms the backing store has been shrunk to a fraction of
the preview (fast frame, low quality); at 244 ms the video is paused at full
preview; at 1767 ms the same full preview carries Oil Paint. V1 will measure all
three with fixed settings and record them.

## 5. Why G1-G21 stayed green

| Symptom | Check that should have caught it | What it actually asserts |
|---|---|---|
| Quality drop while playing | G13 "playback 6 effects stays under budget" | It asserts the opposite: `play_box["backing"] < full_w` is required (`tests/gate/video_check.py`, the `the preview keeps its on-screen size while playing` record). The resolution drop was the designed fix, so the gate locked it in. |
| Paused/playing parity | none | G13 only checks full quality after pausing (`paused video renders at full preview resolution`); there is no same-timestamp parity test while playing or after a seek. |
| Export is a still | none | G13/G21 never check the output bytes or container; G21 calls `export_video_size` with `state.opts.exportFormat='webm'` directly, bypassing the real default UI path. |
| No MP4 | none | No check reads the format list. |
| Seek bar missing | none | G13 checks play/pause only. |
| Output controls disabled | G21 | G21 asserts they are **inert** for video and that export always equals native size — the old decision. That is why the check stayed green. |

## 6. Hypotheses for V1 (each needs a measurement)

1. **Resolution governor** (`app.js:759-761`, `634-674`) is the cause of the
   blocky frames. Evidence: paused 1280×720 vs playing 755×425. **Confirmed.**
2. `state.previewSource` is stale for video: **rejected** — `workerSetSource`
   only sets it for images and `prepareBase` draws `state.video` directly
   (`app.js:906-938`, `engine.js:349-358`).
3. Worker and sync path alternate for video: **rejected** — `workerEligible`
   returns false for any non-image source (`app.js:943`).
4. Seek race: current export waits for `seeked` with a 120 ms fallback
   (`app.js:1814-1815`); no `seeked` listener drives preview. Paused parity
   passes 20/20 in both browsers, so preview seek currently lands correctly, but
   export may still encode an old frame when the fallback fires. To be measured
   in V2.
5. Intended dither/effect patterns: possible contributor to the striped look.
   Paused parity 20/20 with a deterministic stack (posterize+duotone) shows the
   effect output itself is stable; the striped Oil Paint capture must be
   reproduced with a fixed stack before it is called a bug.
6. Oil Paint cost > 1 s: V1 will measure it at the same preview size; every
   shown frame must still pass parity.
